# ADR 0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-10

## Context
We need a record of major technical decisions (escrow partner, NIN provider, demo-day AI agent, offline strategy, etc.).

## Decision
We will write one ADR per major choice in `docs/adr/`, numbered sequentially.
Any decision involving money, health data or compliance gets a second opinion before it is accepted.

## Consequences
Decisions are traceable to PRD requirement IDs and reviewable at each gate.
